# 🚀 エリトラ最高飛行速度 (Max Elytra Fly Speed) - プレイヤーガイド

**Max Elytra Fly Speed** へようこそ！このMODは、Minecraftバニラのエリトラ飛行速度制限を完全に解除し、設定可能な最高速度制限、スムーズなロケット花火の比例加速、そして急降下滑空の空気力学を提供します。

---

## ⚡ 主な機能と飛行ダイナミクス

1. **カスタマイズ可能な最高速度**:
   - バニラMinecraftの速度制限は非常に厳しく設定されています。このMODを使用すると、最高飛行速度を任意の値（デフォルト: `50`ブロック/秒、`100`、`200`、さらには`3000`ブロック/秒まで拡張可能）に設定できます。
2. **2フェーズ速度スケーリング (Dual-Phase Scaling)**:
   - **フェーズ 1 (初期ブースト)**: しきい値速度（デフォルト: `30`ブロック/秒）未満では、バニラの軽快で素早い花火ロケット加速が適用されます。
   - **フェーズ 2 (高速滑空)**: しきい値を超えると、花火ロケットは設定された最高速度に向けて比例的に加速し、わずか2〜3個の花火で100+ブロック/秒まで素早く引き上げます。
3. **急降下時の動的空気抵抗軽減**:
   - 高速設定時、急降下中の空気抵抗が動的に低減され、急降下からの引き起こしによる超高速飛行を維持できます。

---

## ⚙️ ネイティブGameRulesによる設定

このMODはMinecraftのネイティブゲームルールシステムを使用しており、設定ファイルの再読み込みなしでゲーム内から即座に変更が反映されます:

| ゲームルール (GameRule) | デフォルト | 説明 |
| :--- | :---: | :--- |
| `max-elytra-fly-speed:max_elytra_fly_speed` | `50` | エリトラ飛行の絶対最大速度 (ブロック/秒)。 |
| `max-elytra-fly-speed:elytra_initial_boost_speed` | `30` | バニラの高速ブーストが適用される速度しきい値 (ブロック/秒)。 |
| `max-elytra-fly-speed:elytra_high_speed_acceleration` | `15` | 初期ブーストしきい値を超えた際の加速率 (毎ティック15%)。 |

> [!TIP]
> 設定は **「ゲームルールの編集」** メニューまたはコマンド `/gamerule max-elytra-fly-speed:max_elytra_fly_speed <値>` で自由に変更できます。
