# 🚀 겉날개 최대 비행 속도 (Max Elytra Fly Speed) - 플레이어 가이드

**Max Elytra Fly Speed**에 오신 것을 환영합니다! 이 모드는 마인크래프트 바닐라의 겉날개 비행 속도 제한을 완벽하게 해제하여, 사용자 정의 가능한 최고 비행 속도, 매끄러운 폭죽 로켓 비례 가속, 그리고 급강하 활공 유체 역학을 제공합니다.

---

## ⚡ 주요 기능 및 비행 역학

1. **사용자 정의 가능한 최고 속도**:
   - 마인크래프트 바닐라의 기본 속도 제한은 매우 엄격합니다. 이 모드를 사용하면 최대 비행 속도를 원하는 값(기본값: `50` 블록/초, `100`, `200` 또는 `3000` 블록/초까지 확장 가능)으로 자유롭게 설정할 수 있습니다.
2. **2단계 속도 스케일링 (Dual-Phase Scaling)**:
   - **1단계 (초기 부스트)**: 속도 임계값(기본값: `30` 블록/초) 이하에서는 바닐라 고유의 빠르고 민첩한 폭죽 부스트가 적용됩니다.
   - **2단계 (고속 활공)**: 임계값을 초과하면 폭죽 로켓이 설정된 목표 속도를 향해 비례적으로 부드럽게 가속하여 단 2~3개의 폭죽만으로 100+ 블록/초까지 신속하게 도달합니다.
3. **급강하 시 동적 공기 저항 감소**:
   - 고속 설정 시 급강하 중 공기 저항이 동적으로 감소하여, 수직 낙하 후 수평 비행으로 전환할 때 엄청난 속도를 축적하고 유지할 수 있습니다.

---

## ⚙️ 기본 게임 규칙(GameRules)을 통한 간편한 설정

이 모드는 마인크래프트의 자체 게임 규칙 시스템을 활용하므로 설정 파일을 다시 불러올 필요 없이 게임 내에서 즉시 변경 사항이 적용됩니다:

| 게임 규칙 (GameRule) | 기본값 | 설명 |
| :--- | :---: | :--- |
| `max-elytra-fly-speed:max_elytra_fly_speed` | `50` | 겉날개 비행의 절대 최대 속도 (블록/초). |
| `max-elytra-fly-speed:elytra_initial_boost_speed` | `30` | 바닐라 빠른 부스트가 적용되는 속도 임계값 (블록/초). |
| `max-elytra-fly-speed:elytra_high_speed_acceleration` | `15` | 초기 부스트 임계값 초과 시 가속률 (틱당 15%). |

> [!TIP]
> 설정은 **"게임 규칙 편집"** 메뉴 또는 `/gamerule max-elytra-fly-speed:max_elytra_fly_speed <값>` 명령어로 손쉽게 변경할 수 있습니다.
