# 🚀 Максимальная скорость элитр (Max Elytra Fly Speed) - Руководство игрока

Добро пожаловать в **Max Elytra Fly Speed**! Этот мод полностью снимает ванильные ограничения скорости полета на элитрах в Minecraft, предоставляя настраиваемый предел максимальной скорости, плавную кривую ускорения фейерверками и аэродинамику пикирования.

---

## ⚡ Основные возможности и механика полета

1. **Настраиваемый лимит скорости**:
   - Ванильный предел скорости элитр в Minecraft строго ограничен. Мод позволяет установить максимальную скорость на любое значение (по умолчанию `50` блоков/сек, можно установить `100`, `200` или даже `3000` блоков/сек).
2. **Двухфазное масштабирование скорости (Dual-Phase Scaling)**:
   - **Фаза 1 (Начальное ускорение)**: При скорости ниже порога (по умолчанию `30` блоков/сек) применяется резкое ванильное ускорение ракетой.
   - **Фаза 2 (Высокоскоростное скольжение)**: При превышении порога ускорение ракетами становится пропорциональным, плавно разгоняя игрока до целевого лимита всего за 2–3 фейерверка.
3. **Динамическое снижение сопротивления воздуха при пикировании**:
   - При высоких настройках скорости сопротивление воздуха динамически снижается, позволяя развивать и удерживать огромную скорость при пикировании и выходе в горизонт.

---

## ⚙️ Настройка через игровые правила (GameRules)

Мод использует встроенную систему игровых правил Minecraft, изменения применяются мгновенно без редактирования файлов:

| Игровое правило (GameRule) | По умолчанию | Описание |
| :--- | :---: | :--- |
| `max-elytra-fly-speed:max_elytra_fly_speed` | `50` | Абсолютная максимальная скорость полета на элитрах (блоков/сек). |
| `max-elytra-fly-speed:elytra_initial_boost_speed` | `30` | Порог скорости (блоков/сек) для ванильного быстрого ускорения. |
| `max-elytra-fly-speed:elytra_high_speed_acceleration` | `15` | Процент скорости ускорения выше начального порога (15% за такт). |

> [!TIP]
> Параметры можно настроить в меню **«Настройка игровых правил»** или с помощью команды `/gamerule max-elytra-fly-speed:max_elytra_fly_speed <значение>`.
